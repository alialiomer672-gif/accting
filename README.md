# المحاسب — نظام محاسبة متكامل (HTML)

نظام محاسبة عربي كامل يعمل **بدون إنترنت وبدون خادم**، بواجهة RTL عصرية، ويحفظ كل البيانات محلياً في متصفح الجهاز عبر `localStorage`.

## التشغيل

1. افتح الملف `index.html` في المتصفح (نقرة مزدوجة).
2. يعمل التطبيق مباشرة على **بيانات فارغة تماماً** (لا فواتير، لا أصناف، لا أطراف، ولا بيانات شركة)، مع دليل حسابات جاهز فقط.
3. ابدأ بإدخال اسم شركتك في **الإعدادات**، ثم أضف عملاءك وأصنافك.
4. كل التغييرات تُحفظ تلقائياً في المتصفح نفسه.

> لتحميل بيانات تجريبية جاهزة للتجربة: **الإعدادات ← إعادة ضبط + بيانات تجريبية**.

> يعمل أيضاً عبر أي خادم ملفات ثابت (مثل `python -m http.server`) أو داخل أي مجلد مشترك.

## المزايا

- **محاسبة قيد مزدوج** كاملة مع دليل حسابات هرمي (مجموعات وحسابات فرعية).
- **فواتير بيع وشراء** مع أصناف، خصومات، ضريبة، ترقيم تلقائي، ومعاينة/طباعة.
- **ترحيل تلقائي** للفواتير والسندات والمصروفات إلى قيود يومية، مع منع التعديل/الحذف المباشر للقيود المرتبطة.
- **المخزون**: متوسط تكلفة مرجّح عند الشراء، خصم تلقائي عند البيع، أصناف خدمية بدون مخزون، تنبيهات حد إعادة الطلب.
- **الخزينة**: سندات قبض وصرف (مرتبطة بفاتورة أو على الحساب)، ومصروفات تشغيل مع ضريبة مدخلات.
- **العملاء والموردون**: أرصدة الذمم وكشف حساب لكل طرف.
- **التقارير**:
  - قائمة الدخل (الإيرادات، تكلفة المبيعات، مصروفات التشغيل، صافي الربح).
  - الميزانية العمومية مع فحص التوازن.
  - ميزان المراجعة (افتتاحي / حركة / ختامي).
  - دفتر الأستاذ التفصيلي.
  - أعمار الديون (حتى 90 يوم وأكثر).
  - الإقرار الضريبي (ضريبة المخرجات والمدخلات والصافي).
  - تقييم المخزون بالتكلفة وسعر البيع.
  - دفتر اليومية بكل القيود.
- **تصدير** أي تقرير إلى CSV، وطباعة A4 منسقة بترويسة الشركة.
- **نسخ احتياطي**: تصدير/استيراد كل البيانات كملف JSON، وإعادة ضبط ببيانات تجريبية أو مسح كامل.
- **إعدادات** لبيانات الشركة، الضريبة، بادئات الترقيم، وربط الحسابات الافتراضية.
- **وضع ليلي**، وواجهة متجاوبة (جوال/تابلت/سطح مكتب).

## البنية

```
index.html                  # الهيكل الرئيسي وترتيب تحميل السكربتات
assets/
  css/styles.css            # نظام التصميم الكامل + الوضع الليلي + الطباعة
  js/
    utils.js                # مساعدات (تنسيق، تواريخ، مودال، إشعارات، طباعة، ملفات)
    db.js                   # طبقة البيانات (localStorage) + البيانات الأولية
    charts.js               # رسوم SVG بدون مكتبات خارجية
    accounting.js           # محرك المحاسبة: القيود، الأرصدة، التقارير
    views-core.js           # لوحة التحكم، الحسابات، القيود، الأستاذ، ميزان المراجعة
    views-sales.js          # الفواتير، العملاء/الموردون، الأصناف
    views-treasury.js       # سندات القبض/الصرف، المصروفات
    views-reports.js        # التقارير المالية والإعدادات
    app.js                  # القائمة، التوجيه (hash router)، المظهر، الإقلاع
```

## ملاحظات

- البيانات مخزنة بمفتاح `mohasib.v1` داخل `localStorage` في المتصفح — لا تُرفع لأي خادم.
- مسح بيانات المتصفح أو استخدام وضع التصفح الخاص يعني فقدان البيانات، لذا صدّر نسخة احتياطية دورياً من **الإعدادات ← تصدير نسخة احتياطية**.
- لتصفير البرنامج بالكامل (حذف الفواتير والقيود والأطراف والأصناف وبيانات الشركة والإعدادات) مع الإبقاء على دليل الحسابات: **الإعدادات ← مسح كل البيانات**.
- لا توجد أي مكتبات أو خطوط خارجية؛ كل شيء يعمل أوفلاين.
